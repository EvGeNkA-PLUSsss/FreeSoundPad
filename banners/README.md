# FreeSoundPad — Telegram banner

## Files

- `freesoundpad-telegram-1280x640.png` — готовый баннер для Telegram-канала (1280×640).
- `freesoundpad-telegram-2x.png` — исходник 2560×1280 для Retina/пережатия.
- `DESIGN.md` — визуальная философия «Signal Brutalism».
- `src/banner.html` — исходник композиции.
- `app-icon.png` — иконка приложения.
- `fonts/` — используемые шрифты и их OFL-лицензии.

## Параметры

- Формат: PNG, RGB.
- Размер для загрузки: **1280×640** (соотношение 2:1).
- Тёмный фон, мятный сигнальный акцент, техническая типографика.
- Без ссылок и хэндлов — чтобы баннер не устаревал при смене адреса канала.

## Перерендер

Открыть `src/banner.html` в Chrome и снять скриншот 1280×640 (при необходимости с масштабом 2×), затем при необходимости уменьшить до 1280×640.
